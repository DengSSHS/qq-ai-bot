# v0.7.32 · 自动更新闭环打通 + 文档重写

## 自动更新最后三个坑

真机连续验证：仓库停在 v0.7.27 → 让自动更新升到 v0.7.32。

### 1. `dsh-onebot` 起不来

```
Failed to load environment files: No such file or directory
dsh-onebot.service: Failed with result 'resources'.   ← restart counter 46+
```

unit 里 `EnvironmentFile=/opt/dsh/tokenhub.env`，而这个文件**只有 `install.sh` 会创建**。
更新/重装场景下它不存在 → 服务无限自动重启。

→ `update.sh` 每次重启前检查并补建 `tokenhub.env`；`qwen.env` 缺失则警告。

### 2. `git fetch` 没有重试

国内到 GitHub 实测：一次 `GnuTLS recv error (-110)`，一次
`Failed to connect to github.com port 443 after 132396 ms`。以前一次失败就放弃。

→ 重试 3 次、间隔 10 秒；三次都失败才"保持现状不动"。

### 3. 未登录被误判成更新失败

自检要求 QQ 在线，而测试机没扫码 → "更新成功"被判失败并回滚，
把刚升上去的好代码退了回去。

→ 区分两种"QQ 未连接"：

| 情况 | 判定 |
|---|---|
| 容器里没有 onebot 配置（没扫过码） | 环境状态，只 warn，**不回滚** |
| 有配置但连不上（登录过又掉了） | 真故障，回滚 + 通知 |

### 最终实测

```
当前是 detached HEAD（停在 73ee3b3），尝试切回 origin/main
已切回 main（f278c8a / 0.7.31）
代码已是最新（0.7.31），但刚切过分支，补一次部署
自检：QQ 还没登录（这台机器没扫码），不算更新失败
更新成功：0.7.31 → 0.7.31
服务: active
```
