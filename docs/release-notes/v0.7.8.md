# v0.7.8 · 撤回图片专用概率：图和别的消息一样抽

v0.7.7 刚发出去一小时就撤了。原因是你给了两条修正：

> 没必要 @ 我的时候醒，因为很多群都是要这样互动交流的，他这样出来反而会很烦
>
> 这个群识图 30 说错了，他走的应该是那个在群里面抽信息回复的那个

第一条：**被 @ 过之后别人继续发的图，不算叫她**。群聊里 @ 完接着聊是常态，
她每次都跟上去看会很烦。

第二条：**图片不需要独立概率**。它和其他群消息一样，参与“抽中才接话”的那次抽取——
抽中就回（这时自然看图），没抽中就不吱声。

## 因此改了三处

1. **插件回滚**：`inbound.js` / `index.js` 从备份恢复，`imageEngageRate` 补丁彻底撤掉。
   本地补丁数量回到 **5 处**（为它一度变成 6 处）。
2. **配置清理**：`cordis.patch.yml` 里的 `imageEngageRate: 0.3` 连同注释移除。
3. **人设去掉“激活窗口”那条**。

现在只剩三条：

```
① 私聊里主人发图                 → 看
② 群里有人 @ 你，图在那条消息里   → 看
③ 被抽中要主动接一句时看到的图     → 看
```

`casualEngageRate: 0.2` 决定第 ③ 条会不会发生，每小时最多 3 次。
图片没有独立旋钮。

## 一句话反思

同一个功能一晚上改了四次：放宽 → 收紧 → 加专用概率 → 撤回。

根因是我总在“加规则”，而你要的是“少规则，用已有的那套”。
以后碰到“某类消息要不要处理”，先问：**现有机制里是不是已经有一个“要不要理这条”的开关？**
有就复用它，不新开旋钮。
