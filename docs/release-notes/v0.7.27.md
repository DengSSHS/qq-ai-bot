# v0.7.27 · 日记系统：额度被饿死 + 写完不告诉你

> 还有，日记系统是不是出问题了？昨天的日记好像都没看见耶

日记**文件**没坏（10-24 有两条：20:02「沉闷」、22:51「可惜」），坏的是"该发的时候发不出来"和"写完了你不知道"。

## 三个问题，一个是我自己引入的

### 1. 全局额度被主动私聊吃光 → 日记提醒整天不发（我的锅）

`st["count"]` 是所有 routine 共用的，`dailyBudget: 5`。而今天：

```
00:02 casual_dm   count=1
00:22 qzone_daily count=2
07:35 casual_dm   count=3
09:37 morning     count=4
11:07 casual_dm   count=5   ← 满了
```

之后 noon / evening 撞上 `if st["count"] >= budget: break`，**全天不发**。
结果今天只有早上 09:37 一条日记。

修法两条：

- 定时型 routine（morning/noon/evening/night/qzone）**不再受全局额度限制**——
  它们本来每天只触发一次（靠 `fired` 记账），额度在这里没有防护意义；
- 主动私聊不再累加全局 `count`，只记自己的 `dmCount`。

### 2. 窗口太窄 + "过了不补" → 错过就整天丢

| routine | 原窗口 | 现在 |
|---|---|---|
| morning | 09:20–10:40 | 09:20–**11:10** |
| noon | 11:45–13:10 | 11:45–**15:00** |
| evening | 18:40–20:10 | **18:00**–21:30 |
| night | 22:30–23:50 | **22:00**–23:59 |

同时把 `minIdleMin` 全设 0——日记提醒不是"打扰"，不该因为刚聊过就被跳过
（今天 noon 就是这样被跳过的）。

### 3. 我上次把它们设成"写完不要发消息" → 她一直在写，但你完全看不到

上一版为了减噪，给日记 routine 加了尾巴"不要在 QQ 里给主人发消息"。
结果就是你说的"看不见"：她写了，但一声不吭。

改成：写完**发一句很短的话**（不是聊天、不许展开、不许反问）：

```
（这是内部任务。写完日记以后，给主人发一句很短的话就行，
  比如「记下来了，今天有点闷」——一句话，别展开、别问他问题、别把这事当聊天。）
```

## 实测（改完当天就补上了）

```
21:32:01  fired evening at 21:26（count=6，额度闸已移除）
21:32     日记新增：### 2026-10-25 21:32 | 主人 | 有点闷但也算有新东西
21:32:07 她发出：记下来了，今天晚点总算看成B站了，不过最后那个卡死了。
```

## 自验

```
dry-run          evening 从"窗口已过"变成"未到点 21:26"
真实触发         21:32 写出日记 + 发了一句告知
tests 137 passed / preflight 72-0
```

## 一句总结

日记没坏，是**提醒被额度饿死、窗口太窄、写完不出声**三件事叠在一起，
让它看起来像"没写"。这三件都已修。
