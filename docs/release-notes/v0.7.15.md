# v0.7.15 · 私聊刷屏：系统套话混进了聊天

> 他主动性那边，他现在主动发信息好像有点混乱，在我跟他的私聊里面

查日志看到的就是这个：

```
16:09:47  ⏳ 当前任务运行中，新消息已排队，将在当前任务结束后依次处理。
16:10:54  ⏳ 当前任务运行中，新消息已排队，将在当前任务结束后依次处理。
16:13:03  ✅ 已作为补充指令提交给当前任务，模型将在下一步读取。
16:13:03  ✅ 已作为补充指令提交给当前任务，模型将在下一步读取。
```

**这些不是她说的话，是插件的系统播报。** 而且它们写死在代码里，没有开关。

## 两个改动

**1. 静音两条系统播报**

- `⏳ 新消息已排队` —— 排队机制本来就在工作，不需要每次都通知你
- `✅ 已作为补充指令提交` —— 同上

现在你连着发消息，她只是正常回答，中间不再夹着机器套话。

**2. 排队模式改成插话合并**

```yaml
newMessagePolicy: queue   →   steer
```

- `queue`：每条新消息各自排队，任务结束后依次各回一次 → 三条消息 = 三条回复
- `steer`：你在她还在跑的时候发的新消息会并进当前任务，在最近的步骤边界读取 → 通常合成一次回答

实测（连发三条"喂/听得到吗/我先说个事"）：

```
16:14:09  听得到，你说吧。
16:14:23  什么为什么？你话头起了一半就跑了。
16:14:33  谁知道你。刚说要讲个事，然后就没影了。
```

没有系统提示了。仍有 2 条是因为插话只在"任务进行中"才合并——她回完一条、你才发下一条，那自然就是两个回合。这是正常时序，不是 bug。

## 顺带说明「混乱」的另一半原因

今天我把 `injectDryRun` 从 `true` 改成 `false`（v0.7.14），于是**以前从来没发出去的东西现在全发出来了**：
主动私聊、日记提醒、空间说说。加上我在调试时注入了十来条测试消息，
所以这一天看起来格外吵。

现在的节奏应该正常了：主动私聊按概率（晚上更高）、日记提醒一天 4 次、
空间说说晚上一条。如果你觉得还是太频繁，告诉我哪一个，我把它调低或关掉。
