# v0.7.3 · 看图：群里别人发的图也能看，但只看一次

“她只说有图片、不说是啥”——不是工具坏了，也不是模型不支持看图。
是**人设自己把看图锁成了“需要明确许可”**。

## 病因

同一份人设里有两条互相打架的规矩：

```
消息里出现 [图片:路径]：第一个动作就是调用 image_view     ← 121 行
...
别人没有明确要你说那张图，就当没看见。                    ← 124 行
```

她选了保守的那条。于是群里有人发图没点名，她就回：

> 这张图鲸鲸先收下了，不细看了。

## 证据

同一张图，私下问她“这图里是什么”，她答得又准又具体：

```
[工具调用] mcp__vision__image_view(path=…/b2abfa9b.jpg,
           question="这图里是什么？有文字吗？是什么梗？")
[工具结果] 《蔚蓝档案》砂狼白子的 Q 版同人图，银白发、狼耳、蓝围巾、十字发卡…
[她的回复] 白子那张。银白云朵一样的头发，狼耳，蓝围巾，鼓着腮帮子生闷气。
           就是「我不服但我很可爱」那种气鼓鼓。
```

所以视觉链路、模型、图片下载全部正常，问题只在“她愿不愿意看”。

## 改了什么

**1. 人设：从“没许可不看”改成“出现了就看一次，看完就答”**

```
新出现的图看一次，看完就答。不管谁发的——主人、群友、还是陌生人——
只要那张图出现在你正要回应的这条消息里，就先看，再说。
调用完立刻按看到的内容回应，别只说「收到一张图」就结束——那等于白看。
同一张图只看一次……
不看这几类：翻群历史翻到的旧图、自己已经发出去的表情和图片、
以及你正在回应的这条消息之外的图。
```

这样：群里刷图她不会每张都去识别（省额度），但一张图出现在她正在回的对话里，
她就会看，而且会**说出内容**而不是只说“有图”。

**2. `seer.py` 加描述缓存：把“只看一次”变成机制而不只是嘱咐**

key = 路径 + 文件大小 + mtime，命中就直接返回上次的结论，不再打视觉模型。
文件被换成另一张图（大小/mtime 变了）自然失效，不会拿旧描述套新图。

实测同一张图两次调用：

| | 耗时 | 是否调模型 |
|---|---|---|
| 第一次 | 3285 ms | 是 |
| 第二次 | **91 ms** | 否（命中缓存） |

**3. `tests/test_seer_cache.py`**：7 个用例（key 稳定、文件变则失效、put/get、
空值不写、缓存文件是合法 JSON、条目上限）。现在共 121 个测试。

## 自验

```
tests        121 passed（skipped=3）
preflight    71 passed / 0 failed
线上实测     工具调用 → 准确描述 → 她的回复，三段都在会话记录里核过
```

## 没验的

**群聊路径没真走一遍**——需要真人在群里发张图问她。私聊路径已端到端验证。

另外发现一个旧问题（不是这次引入的）：注入通道 `qq-inject.jsonl` 的消息**不会自动回发**，
注入是给“主动说话 / 日记提醒”这类内部提示用的，她的文字输出不会自动发到 QQ。
这意味着 `qqguard` 的“恢复后告知主人”可能也没真发出去——待单独确认。
