# v0.7.13 · 半夜：有的晚上失眠，有的晚上睡得沉

> 不是这个概率也是随机的，可能每天都失眠什么之类的，
> 比如说跟白天那个一样，如果你一整个白天都没来找他，他就会来晚上来问你

v0.7.12 的夜间路线是「每晚固定 5%」，那不像活人——活人不是每晚都失眠。

## 改成按天的稳定随机

用日期哈希决定「今晚失不失眠」，所以同一个晚上跑多少次结果都一样（不会抖）：

```
约 35% 的晚上是失眠夜 → 冲动 ×3
其余 65% 是睡得沉     → 冲动 ×0.2
```

## 再加「白天没聊，晚上更可能来」

夜间也吃空闲加成，但改成了**乘性**——空闲只放大她本来就有的冲动，
而不是给「睡得沉」的夜晚垫一个下限。

> 第一版用加性（base + bonus），结果睡得沉的夜晚因为空闲久，
> 概率涨到 12%/小时 → 一晚约 50% 会发，等于每晚都来，与需求相反。

## 实测分布

每晚 6 个整点桶、每晚上限 1 条：

| 今夜 | 白天聊过（空闲 1h） | 半天没聊（8h） | 全天没聊（14h） |
|---|---|---|---|
| **失眠夜**（≈35%） | 27% | 47% | **58%** |
| **睡得沉**（≈65%） | 2% | 4% | 5% |

也就是：多数晚上她一觉到天亮；三成左右的晚上会失眠；
那天你要是整天没找她，失眠夜里来的概率接近六成。

## 顺带修掉一个会让她半夜永远发不出的 bug

白天和半夜原来共用一个计数器 `dmCount`。白天发过 3 次之后，
半夜那条判断 `dmCount(3) >= 1` → 直接被拦，**永远发不出来**。

改成每条路线独立计数（`dmCount_<id>`）。

## 自验

```
python3 proactive.py --dry-run
  [casual_dm]        刚聊过（3 分钟前 < 60），不打扰          ← 白天有冷却
  [casual_dm_night]  空闲 3 分钟｜本轮概率 5%｜掷出 0.88 -> 不发  ← 夜间无冷却
跨天模拟（14 晚）：失眠夜 5 晚，睡得沉 9 晚，分布符合上表
py_compile / JSON 校验通过
```

## 仍存在的老问题

`idle_minutes()` 依赖的 `qq-actions.log` 从未生成，所以空闲恒为无穷大。
夜间这一项影响不大（乘性加成最多放大到 3 倍），但白天会一直跑在
「半天没聊」那一列。下一版改用真实发言时间。
