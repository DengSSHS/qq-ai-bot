# v0.7.11 · 主动私聊：以前一天只能发 3 次，现在按作息分配

> 为什么现在这么久过去了，还是没有随机到主动性给我发消息这种私聊

查了下，机制一直在跑（`proactive.timer` 每 10 分钟一次），**今天也确实发过 3 次**：

```
00:02  casual_dm
07:35  casual_dm
11:07  casual_dm     ← 之后一整天再没发过
```

## 两个原因叠在一起

**1. 日记提醒把主动额度吃光了**

`schedule-state.json` 里的 `count` 是**所有 routine 共用**的，`dailyBudget: 5`：

```
count = 5（含 morning 日记提醒、qzone_daily 空间提醒、3 次主动私聊）
→ 11:07 之后额度耗尽，一整天不再主动
```

也就是说：5 次额度里真正用于“主动找你聊天”的只有 3 次，剩下两次被定时提醒占了。

**2. 概率不分时段**

`Casual_dm` 全天同一个概率曲线，睡眠时段（01:00-07:30）之外一律按“空闲越久越可能”算。
但她自己是有作息的（`body_state.py` 里写着：半夜很困、清晨刚醒、晚上精神最好）——
主动找一个刚睡醒的人、和一个晚上最有精神的人，概率不该一样。

## 改了三处

### 一、主动私聊独立额度

`casual_dm` 用自己的 `dailyBudget: 8`，日记/空间提醒不再吃它的预算。

### 二、概率跟作息时段走

`proactive.py` 新增 `SLOT_MULT`，按 `body_state` 的时段划分给概率乘一个系数：

| 时段 | 系数 | 空闲够久时的概率 |
|---|---|---|
| 01:00-07:30 | — | **静默**（睡觉，不打扰） |
| 07:30-09:00 刚醒 | 0.3 | 24% |
| 09:00-11:00 上午 | 0.9 | 72% |
| 11:00-13:00 中午 | 0.6 | 48% |
| 13:00-15:00 午后犯困 | 0.4 | 32% |
| 15:00-18:00 下午 | 1.0 | 80% |
| 18:00-20:00 傍晚 | 1.1 | 80% |
| 20:00-23:00 晚上 | 1.3 | 80% |
| 23:00-01:00 深夜 | 0.7 | 56% |

### 三、修正系数的作用方式（第一版写错了）

第一版写成 `prob = min(cap, ramp * mult * (1 + hours))`，结果**闲置一久就把系数差异抹平了**——
除了刚醒和午后，其余时段全是 80%，等于没做区分。

改成让系数决定**天花板**：

```python
prob = min(cap * mult, ramp * (1 + hours))
# 时段决定「这个时段最多多主动」，累积决定「这次有没有想起你」
```

## 自验

```
python3 proactive.py --dry-run   → 概率/掷数/是否发，三个数都打出来
时段抽查 08:00=24% 14:00=32% 20:00=80% 01:00-07:00=静默
语法 py_compile 通过；dmCount 已归零（新额度立刻生效）
```

## 一个没解决的底层问题

`idle_minutes()` 是用 `media/onebot/qq-actions.log` 的 mtime 估算的，
但**那个文件从来没生成过**（插件的 `actionAuditEnabled` 没开），于是 `idle` 恒为无穷大：

```
→ 概率永远按"空闲很久"算 → 一有额度就发
```

所以真正的“多久没说话”其实没被算准。要算准得开插件的 `actionAuditEnabled`，
或者改成记录她最后一次**实际发言**的时间。这次没动，先记着。
