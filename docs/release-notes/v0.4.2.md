## 修掉的问题

原来未知 id 的兜底是：

```js
return FACE_EMOJI[id] ?? '😀';    // 不认识的就当笑脸
```

`FACE_EMOJI` 只收了两百来个，QQ 实际有几百个。剩下的一律变 😀 ——
**她会看到不存在的笑**。

具体后果不是"显示不好看"，而是**情绪判断错**：

```
别人发：😭（哭）但 id 不在表里 → 她读到 😀
她回："哈哈这么开心啊"
```

现在未知 id 返回 `[表情]`：宁可老实说"这里有个我认不出的表情"，
也不要猜错情绪。她看到 `[表情]` 会知道"对方发了什么但有东西我看不明白"，
可以问一句，而不是自作聪明。
