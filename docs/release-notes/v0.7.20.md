# v0.7.20 · 自动更新改成默认关闭 + 两道保护

> 把我的自动更新关了吧，因为反正我这边是个人开发者，所有开发都在我这边。
> 我这边肯定是不需要自动更新，然后，这个自动更新肯定是不能对他那边造成影响的，
> 也不能对这一整个对话造成影响，也不能对记忆什么之类的造成影响

## 三件事

**1. 本机已关闭**

```
auto_update        关
自动更新定时器     disabled / inactive / 没有下次运行
手动跑脚本         → 跳过：switches.py 里 auto_update = 关
```

**2. 改成装机默认关闭**

`install.sh` 不再 `enable` 它，只打印提示：

```
[OK] 自动更新未开启（默认；要开：switches.py on auto_update）
```

理由就是你这句话的两半：开发者的机器该自己控制升级时机；别人的机器也不该
在你不知道的情况下变样。

**3. 加两道保护，即使开着也不会乱动**

```
最近 15 分钟有对话活动        → 跳过本次（不打断正在进行的交谈）
memory-distill / sticker-settle 正在跑 → 跳过（不和文件写入撞）
```

实测（`touch` 一个会话文件模拟刚聊过，然后打开开关跑）：

```
跳过：15 分钟内有对话活动（onebot-private-1709392682-mvnjkj9n），不打断
```

## 关于「不影响对话和记忆」

`update.sh` 实际只写三处：

| 写什么 | 内容 |
|---|---|
| `cordis.patch.yml` | 只补缺失的键，已有值一字不改 |
| `routines.json` | 只添加新 routine，不覆盖已改 prompt |
| `node_modules/…` | 重装 fork 快照 + 重打补丁 |

grep 过整个脚本：**一次都没提到** `sessions/`、`memory/`、`workspace/`、
`persona/`、`media/`。对话历史、日记、长期记忆、人设、表情库都不在它的写入范围内。

重启也不会丢会话：会话落在磁盘上，dsh 起来会自己 attached（平时手动重启也是这样）。

## 自验

```
本机：开关 off → 脚本跳过；定时器 disabled
保护：touch 会话文件后 → 正确跳过
update.sh grep：不涉及 sessions/memory/workspace/persona/media
```

## 一个诚实的提醒

「不影响对话」有两层意思，我只保证了第一层：

- ✅ **不主动打断**：15 分钟内有活动就不升级
- ⚠️ **升级本身仍然会重启一次**：如果恰好在你发消息的那一两秒执行，那条消息会失败。
  04:00 执行、且要求前 15 分钟无活动，实际很难撞上，但不是零概率。
