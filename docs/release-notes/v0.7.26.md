# v0.7.26 · B 站记忆：以前刷过就忘，因为压根没存

> 还有他那个B站的那个记忆是不是出问题了

是出问题了，但**不是检索坏了，是根本没存**。

## 现状（查证）

| 文件 | 记什么 |
|---|---|
| `bili-share.jsonl` | 只记“分享到评论区”的那几次 |
| `bili-window.log` | 只记开窗/关窗 |
| 日记 | 只有 2 条偶然提到 B 站 |

也就是说：**她刷了 5 个视频，只要没分享、没写进日记，就等于没发生过。**
事后问她“你之前看了什么”，她只能凭印象答——昨天那句“没看成、工具不在手上”
就是这么来的。

## 改法：看了就落一行盘

`bili_hub.py` 里 `read_video` / `get_video_job` 成功后追加到
`memory/bili-watched.jsonl`：

```json
{"ts": 1792934275, "bvid": "BV1rAWc6YEFb", "title": "3分钟看懂2026诺贝尔化学奖…",
 "summary": "…", "speech": "unavailable"}
```

配套给记忆 MCP 加了 `bili_watched(query, n)`：按标题/摘要关键词搜，不传就返回最近的。

## 三个踩过的坑（都是靠真实返回才发现的）

**1. 字段位置错了**：`bvid` 在 `result` 里，不在顶层。
第一版直接从顶层取，记录永远是空的。

**2. 字幕文字叫 `content` 不叫 `text`**
```json
"speech": {"entries": [{"start": 0.1, "end": 1.1, "content": "说起海藻"}]}
```
用 `text` 取到的是空字符串——记录里只有 bvid。

**3. 返回里根本没有 `title`**
多数视频 `result` 里没有标题字段。没字幕的视频就变成
`{"bvid": "BV...", "title": "", "summary": ""}` ——记录等于废的。
所以没标题时补一次 `get_video_info`（同一个 bvid），把标题抓回来，并记下字幕状态
（`available` / `unavailable`），事后能分辨“看懂了”还是“只看了个标题”。

## 还要让"她会去查"才算闭环

工具加了不等于会用（`diary_recent` 就是个例子：196 轮只调过 1 次）。

所以同时改了两处：
- `MEM_HINT`（回忆触发词的提醒）里点名：问到 B 站看过什么用 `bili_watched`
- 人设的记忆工具清单里加上 `bili_watched`

## 自验

```
真实流程（read_video → get_video_job succeeded）→ 记录写入
字幕可用   → summary 是字幕拼的（"说起海藓不开花"）
字幕不可用 → 标题从 get_video_info 补上（"3分钟看懂2026诺贝尔化学奖…"），speech=unavailable
bili_watched("塔防")     → 正确命中
bili_watched()（不传词）  → 返回最近几条
tests 137 passed / preflight 72/0
```

## 没验的

- 一次**真实**的“她刷完 → 隔天问她”闭环（需要等一天）
- 视频任务卡住（`state: running` 不动）时会跳过记录——这是有意的（只记成功的），
  但意味着“卡住的视频”也不会留痕
