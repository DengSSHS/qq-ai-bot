## ⚠️ 这个版本装不上，请用 [v0.2.1](https://github.com/DengSSHS/qq-ai-bot/releases/tag/v0.2.1)

`v0.2.0` 在干净机器上部署会失败。`install.sh` 装 profile 依赖时 npm 直接拒装：

```
npm error code ERESOLVE
npm error Could not resolve dependency:
npm error Conflicting peer dependency: @deepseek-ai/dsh-llm@0.2.0-rc.2
npm error   peer ... from dsh-onebot-qq@0.9.3
```

原因是 `dsh-onebot-qq` 要求 `@deepseek-ai/dsh-llm >=0.2.0-rc.1`，而
`@deepseek-ai/dsh-mcp-client@0.0.1-rc.1` 声明 peer `^0.0.1-rc.1`，两条要求
在 npm 7+ 的严格 peer 解析下互相排斥。

线上那套组合一直跑得好好的，说明当初是用 `--legacy-peer-deps` 装进去的
——但这个参数从没写进脚本。**在我自己机器上能跑，不等于别人能装上。**

## 请用 v0.2.1

[v0.2.1](https://github.com/DengSSHS/qq-ai-bot/releases/tag/v0.2.1) 修掉了这个问题，
并在 Ubuntu 24.04 容器里从零跑过 `install.sh`，1~7 阶段全过。

## 这个版本本来包含什么

功能本身都是好的，全部包含在 v0.2.1 里：

- 收图链路闭环（每天 03:00 结算后把待收清单递给她，她自己入库）
- 表情库清重复（109 组 / 115 条）、感知哈希 8×8 → 16×16
- 场景分类 prompt 加固 + 解析三层兜底
- 跨群长期记忆（每天 03:10 蒸馏，写进 `AGENTS.md` 每轮注入）
- 调用记账 + 排障报表
- 修复提示前缀，缓存命中 0% → 24%

保留这个标签只为历史，**不要用它部署**。
