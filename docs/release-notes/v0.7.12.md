# v0.7.12 · 主动私聊：从「越不理我越急」改成「她自己会想你」

> 我需要的就是，在你不主动找他的时候，他有概率来找你，
> 同时，他晚上来找你的概率也不为零，就是这样子的话，才有那种活人的感觉
>
> 然后这个也要跟他的那个睡眠时间是要有交集的，然后，晚上睡眠时间他也肯定会来找你啊，
> 比如说，他会说什么失眠睡不着啊这些什么之类的

## 上一版错在哪

v0.7.11 的公式是：

```python
if idle < 60分钟: 跳过        # 刚聊完就一定不发
prob = ramp * (1 + 空闲小时数)  # 越久没聊越可能
```

这是「粘人」模型，不是「活人」模型。它说的事情是：

- 你刚跟她聊完 → 她绝不会主动找你（概率 0）
- 你越不理她 → 她越急着找你

长期下来她只会显得焦虑，而不是「这个人自己会想起你」。

## 改成了「基础冲动 + 加成」

```python
base       = 0.06   # 她本来就有的说话冲动（不为 0）
idle_bonus = min(0.30, 0.05 * 空闲小时数)   # 久没聊会想，但只是加成
prob       = min(cap, (base + idle_bonus) * 时段系数)
```

实测各时段的概率：

| 时间 | 刚聊完 | 聊完 1 小时 | 半天没聊 |
|---|---|---|---|
| 08:30 刚醒 | 2% | 3% | 11% |
| 10:00 上午 | 5% | 10% | 32% |
| 12:00 中午 | 4% | 7% | 22% |
| 14:00 午后 | 2% | 4% | 14% |
| 16:00 下午 | 6% | 11% | 36% |
| 19:00 傍晚 | 7% | 12% | 40% |
| **21:00 晚上** | **8%** | **14%** | **47%** |
| 23:00 深夜 | 4% | 8% | 25% |

关键变化：**刚聊完也不再是 0**。她会「突然想起你」，不只是「你不理她所以着急」。

## 半夜：她也会失眠

新增一条独立路线 `casual_dm_night`：

```json
{
  "id": "casual_dm_night",
  "window": ["01:00", "06:30"],
  "ignoreQuiet": true,        // 允许突破睡眠静默
  "minIdleMin": 0,            // 不设冷却：她半夜醒来跟你多久没说话无关
  "dailyBudget": 1,           // 每晚最多 1 次
  "baseChance": 0.05,         // 每次检查 5%
  "idleBonusCap": 0,          // 不吃"多久没聊"的加成
  "prompt": "（半夜醒了）这个点你还醒着吗……鲸鲸睡不着，翻来覆去好久了。
             要是你也醒着，陪我说两句；要是你睡了，别回，我自己再躺会儿。"
}
```

为了让这条能生效，`in_quiet` 的全局拦截改成了**按 routine 豁免**（`ignoreQuiet`）。
其他提醒（日记、空间说说）仍然老老实实睡觉时段不打扰。

## 为什么半夜这条不吃「空闲加成」

因为它的语义不是「你太久没理我」，而是「**我自己醒了**」。
所以它跟你有没说话无关，只看她自己的概率——每晚大概一次机会，5% 命中，上限 1 次。

## 自验

```
dry-run（16:00 档）：
  [casual_dm]        刚聊过（3 分钟前 < 60），不打扰        ← 白天有冷却
  [casual_dm_night]  空闲 3 分钟｜概率 5%｜掷出 0.88 -> 不发  ← 半夜无冷却
语法 py_compile 通过
```

## 一个仍然存在的底层问题

`idle_minutes()` 读的是 `qq-actions.log` 的 mtime，而那个文件从未生成
（插件 `actionAuditEnabled` 没开），所以 idle 恒为无穷大 → 一律按"半天没聊"算。

这意味着上表里「刚聊完 8%」实际上很少用到，多数时候跑的是「半天没聊 47%」那一列。
要精确，得改成记录她最后一次真实发言时间——下一版再做。
