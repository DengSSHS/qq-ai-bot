一套自托管的 QQ AI 机器人部署包：DeepSeek Harness + NapCat + 一个绑定在 QQ 上的角色。跑在你自己的一台 Ubuntu 上，数据都在本机。

这一版没有新功能堆砌，主要是**把三个「存了但没用上」的死角补掉**，顺手修了一个让新人都装不上的安装 bug。

## 安装

```bash
git clone https://github.com/DengSSHS/qq-ai-bot.git
cd qq-ai-bot
cp deploy.env.example deploy.env   # 填 6 项：两个 QQ 号、模型地址/模型名/key、人设模式
sudo bash install.sh
```

需要一台 **Ubuntu 22.04 / 24.04、x86_64、≥2GB 内存、≥10GB 磁盘**的机器。

## 这一版改了什么

### 收图链路闭环

之前群友发的图会被收进 `pending/`，然后**没有下文**——真正入库是 QQ 插件的私有能力，Python 侧调不到，而凌晨 3 点没人醒着。

现在每天 03:00 结算后，会注入一条消息把待收清单递给她，她自己 `sticker_ingest` + `qq_save_sticker` 完成入库。走的是插件正规 API，不停服、不改索引。

### 表情库清重复

全库扫出 109 组重复（115 条），逐对用模型确认后清理，文件移到 `dupes/` 留底，索引/标签/附加数据同步移除，可逆。

顺带把感知哈希从 8×8 提到 16×16：

| | 误拦率 | 同图变体召回 |
|---|---|---|
| 8×8 | 0.123% | 100% |
| **16×16** | **0.004%** | **100%** |

精度白拿一个数量级，所以近似重复从「只提示」改成「默认拦 + `force` 出口」。

### 场景分类标准加固

分类 prompt 只列标签名时，模型会把 65% 的图倒进最泛的那一类（「卖萌可爱」）。加上适用条件和三条硬规则后降到 24%，散布到 11 个标签。

解析也加了兜底：小样本串行跑 29/29 全中，并发跑 754 张时模型开始抄 prompt 里的格式模板、加 markdown、甚至拒绝回答——三层兜底（JSON → 竖线兼容 → 全文搜标签）才拦得住。

### 跨群长期记忆

存储一直有、注入通道一直没接：`notes.md` 三个预留区块全是「（还没记）」，五个记忆工具真实调用 **0 次**，`AGENTS.md` 在 21956 行会话里只出现 8 次（`agent-instructions` 插件被禁用）。

现在每天 03:10 蒸馏全部会话，产出带证据的知识条目（`count` / 首次 / 最近 / 来源），写进 `AGENTS.md` 托管区，每轮注入。

- **单一知识池，跨群共用**：每条带 scope（通用 / 某群 / 某私聊），注入时标来源
- 只观察到一次的标「（单次）」，不当定论
- 过滤会过期的运行状态（模型名、接口、数量）和工具能力断言

### 调用记账 + 排障

三个上游入口（网关 / 看图 / 蒸馏）都记，每行带 `status`、`dur_ms`、请求体积、错误摘要，**失败也记**。

```bash
python3 usage_log.py --days 7      # 花了多少
python3 ops_report.py --hours 24   # 哪里不对：失败率、延迟分位、工具失败 top
```

价格填 `memory/usage_prices.json`；没填就记 `null`，不编假金额。

## 修掉的两个真 bug

**1. 提示前缀每轮都变，缓存命中率一直是 0**

`bridge.js` 把精确到秒的「当前时间」拼在系统提示第 0 位，后面 12KB 系统提示 + 11KB 工具定义全部作废。挪到末尾后：

```
cached 0 → 7168，命中率 0% → 24%
```

**2. v0.2.0 在干净机器上装不上**

`install.sh` 装 profile 依赖时 npm 直接 ERESOLVE 拒装：`dsh-onebot-qq` 要求 `dsh-llm >=0.2.0-rc.1`，而 `dsh-mcp-client@0.0.1-rc.1` 声明 peer `^0.0.1-rc.1`。线上那套组合一直跑得好好的，说明当初是用 `--legacy-peer-deps` 装进去的，但参数没写进脚本。

这一版补上了，并把 `dsh-onebot-qq` 钉死到 `0.9.3`（`^` 会拉到 0.9.5，peer 要求更高，必炸）。

## 已知限制

- 提示词的工具定义和对话历史**不参与缓存**（上游只缓存固定一段），历史会随对话增长
- `prompt.js` / `bridge.js` 是本地改的插件文件，插件升级会被覆盖，改法记在 `docs/sticker-library.md`
